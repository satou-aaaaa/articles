カルカソンヌはタイルが72枚あり、内1枚は初期タイルで、残りの71枚をふたりで分け合うゲームです。
先手は36枚のタイルを利用でき、後手は35枚のタイルを利用できます。
先手のほうがタイルを1枚多く利用できますが、極端に先手有利な訳ではありません。
[先手と後手のどちらが有利？](caa0303240044e4c85c71338166302fd.md)
# 特定の一枚のタイルを次の一手で引く確率
特定の1枚のタイルを引く確率について考えてみましょう。
土管(紋章無し)は1枚しかありません。

![](../files/45616752a93c4935828c2cc7202004b8/土管.png)

先手の一手目で土管(紋章無し)を引く確率　はどのくらいでしょうか？
次の式で計算できます。
次の一手で引く確率(%) = 対象のタイルの枚数 ÷ 残りの全てのタイル枚数 x 100

つまり、次のようになります。
1 ÷ 71 = 約1.4%
約1.4%が、先手の一手目で土管(紋章無し)を引く確率です。

注意点は、残りの全てのタイル枚数は毎ターン変わることです。
特定の一枚のタイルを次の一手で引く確率を、残りの全てのタイル枚数ごとに見てみましょう。

| 残りの全てのタイル枚数(枚) | 特定の一枚のタイルを次の一手で引く確率(%) |
| --- | --- |
| 70枚 | 約1.429% |
| 60枚 | 約1.667% |
| 50枚 | 2% |
| 40枚 | 2.5% |
| 30枚 | 約3.333% |
| 20枚 | 5% |
| 10枚 | 10% |
| 5枚 | 20% |

グラフにすると、次のようになります。
> （Notion の埋め込み（drive）は移せませんでした。元ページで見てください）

残り20枚で5%、残り10枚で10%、それ以降は急に特定の一枚のタイルを引く確率が上がっています。
# 特定の一枚のタイルをゲーム終了までに引く確率
先ほどまでは、次の一手で特定の一枚のタイルを引く確率を見てきましたが、ゲーム終了時までに引ける確率を見てみましょう。
先手と後手で、最終的に引けるタイルの枚数が異なります。

|  |  |
| --- | --- |
| 先手 | 36枚 |
| 後手 | 35枚 |

つまり、先手と後手で特定の一枚のタイルをゲーム終了までに引く確率も変わります。

|  |  |
| --- | --- |
| 先手 | 約50.7% |
| 後手 | 約49.3% |

カルカソンヌでは、特定の一枚のタイルをゲーム終了までに引く確率を、50％として考えます。
次の図は、待ちタイルを引ける確率を表しています。

| 残り待ちタイル枚数(枚) | 待ちタイルを1枚は引ける確率(%) |
| --- | --- |
| 1 | 50% |
| 2 | 75% |
| 3 | 87.5% |
| 4 | 93.75% |
| 5 | 約99.97% |

残り待ちタイル枚数2枚までは、大会の解説等で良く使われます。
残り待ちタイル枚数1枚の場合は**「50%タイル」**と呼びます。
残り待ちタイル枚数2枚の場合は**「75%タイル」**と呼びます。
